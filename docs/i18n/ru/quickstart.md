# Быстрый старт

![Бости набирает код в терминале](assets/mascot/bostie-quickstart.webp){ align=right width="180" loading=lazy }

На этой странице вы создадите приложение Discord, добавите его на сервер и запустите бота с одной слэш-командой. Предполагается, что bostie уже [установлен](install.md).

{% include "callout.md" %}

## Создайте приложение { #create-the-application }

1. Откройте [Developer Portal](https://discord.com/developers/applications) и создайте приложение.
2. На его странице **Bot** сбросьте токен и скопируйте его. Любой, у кого есть токен, управляет ботом, поэтому не держите его в коде и в репозитории.
3. На его странице **Installation** добавьте области доступа `applications.commands` и `bot` в установку на сервер, затем откройте ссылку установки и добавьте приложение на сервер, которым вы управляете.

## Напишите бота { #write-the-bot }

Сохраните это как `bot.py`:

```python
--8<-- "docs/snippets/quickstart/hello_bot.py"
```

`@bot.command` превращает функцию в слэш-команду `/hello`. Её имя — это имя функции, а описание — первая строка докстринга. `ctx` — это [`Context`](guide/responses.md) одного использования команды: кто её запустил, где, и методы, которыми на неё отвечают.

## Запустите его { #run-it }

Передайте токен через переменную окружения `BOSTIE_TOKEN` и запустите файл:

```sh
export BOSTIE_TOKEN="your token"
python bot.py
```

`bot.run()` настраивает логирование на уровне INFO, подключается и сравнивает определённые вами команды с теми, что зарегистрированы в Discord. При первом запуске он регистрирует `/hello` и пишет в лог `commands synced (global): added ['hello'], ...`; при следующих запусках ничего не отправляется, пока какая-нибудь команда не изменится. Введите `/hello` на своём сервере, и бот ответит.

Ctrl+C или SIGTERM от менеджера процессов корректно закрывает бота.

## Добавьте параметр { #add-an-option }

Параметры функции после `ctx` становятся параметрами команды, а их тип задают аннотации:

```python
--8<-- "docs/snippets/quickstart/roll_bot.py"
```

`sides` — целочисленный параметр от 2 до 100 со значением по умолчанию 6, поэтому Discord показывает его как необязательный и отклоняет значения вне диапазона ещё до того, как их увидит бот. Перезапустите бота, и он отправит изменённую команду.
