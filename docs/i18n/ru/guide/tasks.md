`every(seconds=300)` запускает функцию, как только бот готов, а затем каждые 300 секунд. Расписание не уплывает: каждый запуск начинается на следующем кратном `seconds` от первого, а запуск, длящийся дольше `seconds`, пропускает такты, на которые пришёлся.

`every(time=...)` запускает её каждый день в одно время суток или в каждое из нескольких. `datetime.time` без `tzinfo` задано в UTC. С фиксированным смещением, как выше, время остаётся с этим смещением; с `zoneinfo.ZoneInfo` оно следует за переходами на летнее и зимнее время в этой зоне. Передавайте `seconds` или `time`, но не оба сразу.

## Управление задачей { #controlling-a-task }

```python
--8<-- "docs/snippets/tasks/task_control.py"
```

`@bot.every` возвращает `Task`, а ожидание `check_feeds()` по-прежнему один раз выполняет функцию. Его методы меняют расписание, пока бот работает:

| `Task` | Что делает |
|---|---|
| `stop()` | отменяет задачу — во время запуска или между запусками — и не даёт ей стартовать вместе с ботом до `start()`; если вызвать до запуска бота, задача ждёт `start()` |
| `start()` | запускает задачу, пока бот готов, — с этого момента, если он уже готов; уже работающая задача продолжает как прежде |
| `restart()` | отменяет задачу и запускает её заново, так что задача с интервалом выполняется сразу |
| `change_interval(seconds=...)` или `change_interval(time=...)` | переключает на новое расписание; ожидание отсчитывается заново с момента изменения или с конца текущего запуска |
| `count` | сколько запусков завершилось с последнего старта задачи |
| `seconds`, `times` | расписание, которому она следует |
| `@task.before`, `@task.after` | регистрируют `async def hook()`, которого дожидаются при каждом старте задачи и при каждой её остановке — через `stop()`, `restart()`, исключённый роутер или `close()` |

Исключение в хуке отправляется как `TaskError`, так же как исключение в запуске. Если хук `before` выбрасывает исключение, задача остаётся остановленной до `restart()`.

## Когда выполняются задачи { #when-tasks-run }

Задачи стартуют, когда бот отправляет `Started`, а `close()` отменяет их до закрытия HTTP-клиента. Задача, зарегистрированная на роутере, который включается позже, стартует, как только его включат, а задача, чей роутер исключён, отменяется. Приложение, которое обслуживает только [`ASGIApp`](http-interactions.md), запускает свои задачи при старте приложения.

Функцию можно зарегистрировать как задачу только один раз. Чтобы выполнять один и тот же код по двум расписаниям, зарегистрируйте две функции.

## Когда задача выбрасывает исключение { #when-a-task-raises }

Исключение в запуске отправляется как событие `TaskError` с `task` — `Task`, который выбросил исключение, — и `error`, и задача снова выполняется в своё следующее время. Если слушателя `TaskError` нет, bostie пишет исключение в лог с трассировкой.
