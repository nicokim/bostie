# Слэш-команды

![Бости пишет слэш-команду в облачке с репликой](../assets/mascot/bostie-commands.webp){ align=right width="180" loading=lazy }

Слэш-команда — это асинхронная функция с декоратором `@bot.command`. Её первый параметр принимает [`Context`](responses.md); каждый следующий параметр — это параметр команды.

```python
--8<-- "docs/snippets/commands/option_types.py"
```

Команда называется `/report`. Её имя — это имя функции, а описание — первая строка докстринга; `@bot.command(name=..., description=...)` задаёт их явно, а команда без того и другого получает описание `…`. Работают и `@bot.command`, и `@bot.command(...)` — как на боте, так и на [роутере](routers.md).

## Типы параметров { #option-types }

Аннотация типа параметра выбирает тип параметра команды, а обработчик получает уже преобразованное значение:

| Аннотация | Параметр Discord | Обработчик получает |
|---|---|---|
| `str` | строка | текст |
| `int` | целое число | `int` |
| `float` | число | `float`, даже если пользователь ввёл целое число |
| `bool` | логическое значение | `bool` |
| `User` | пользователь | `User` |
| `ResolvedMember` | пользователь | участника вместе с его `user`; только на серверах |
| `Role` | роль | `Role` |
| `PartialChannel` | канал | канал в том виде, в каком его разрешило взаимодействие |
| `Attachment` | вложение | `Attachment` загруженного файла |
| `User \| Role` или `ResolvedMember \| Role` | упоминаемый объект | то, что выбрал пользователь |
| `Literal[...]` или `Enum` | строка, целое число или число с вариантами | литерал или член перечисления |

Аннотация, которой нет в таблице, вызывает `CommandDefinitionError` при выполнении декоратора. Для параметра-канала аннотация — `PartialChannel`, а не `Channel`, а для участника — `ResolvedMember`, а не `Member`: взаимодействие несёт именно эти частичные объекты, о чём и говорит сообщение об ошибке.

## Обязательные и необязательные { #required-and-optional }

Параметр без значения по умолчанию обязателен. Значение по умолчанию или `| None` в аннотации делают его необязательным; необязательный параметр, который пользователь не указал, получает значение по умолчанию или `None`. Discord требует, чтобы обязательные параметры шли первыми, и bostie сам сортирует их так при сборке команды, в каком бы порядке ни шли параметры функции.

## Диапазоны и настройки параметров { #ranges-and-option-settings }

`Range[int, 1, 10]` — параметр `int` от 1 до 10 включительно. `Range` принимает и `float`, а для `str` границы задают длину: `Range[str, 1, 2000]`. Всё остальное задаёт `Option(...)` в `Annotated`, и он важнее того, что следует из аннотации:

```python
--8<-- "docs/snippets/commands/option_settings.py"
```

| Поле `Option` | Применяется к | Значение |
|---|---|---|
| `name` | всем | имя параметра в Discord; параметр функции сохраняет своё имя в Python |
| `description` | всем | описание, если в `Annotated` нет строки |
| `name_localizations`, `description_localizations` | всем | текст для каждой локали, например `{"fr": "salon"}` |
| `min`, `max` | целому числу, числу | границы включительно, в пределах ±2⁵³ |
| `min_length`, `max_length` | строке | границы длины: от 0 до 6000 и от 1 до 6000 |
| `channel_types` | каналу | типы каналов, которые может выбрать пользователь |
| `file_types` | вложению | до 10 значений из `image`, `video`, `audio` или расширений вроде `.pdf` |
| `choices` | строке, целому числу, числу | фиксированные варианты; см. ниже |
| `autocomplete` | строке, целому числу, числу | функция, которая предлагает значения, пока пользователь печатает |
| `extra` | всем | сырые поля, которые добавляются в JSON параметра, — для поля, которое bostie ещё не моделирует |

Поле, указанное для типа параметра, к которому оно не применяется, вызывает `CommandDefinitionError`.

## Варианты { #choices }

`Literal` или `Enum` предлагают фиксированный список. Вариант из `Literal` называется по своему значению; вариант из `Enum` называется по имени члена и отправляет значение члена. `Option(choices=[...])` переименовывает или локализует их, если перечисляет те же значения в том же порядке:

```python
--8<-- "docs/snippets/commands/option_choices.py"
```

Обработчик `/order` получает `"tea"`, `"coffee"` или `"water"` для `drink`, член `Size` для `size` и значение выбранного `Choice` для `milk`. При простой аннотации `str`, `int` или `float` варианты задаёт один только `Option(choices=[...])`; каждый из них — это `Choice(name, value)` или просто значение, которое называется само по себе. Значения вариантов должны иметь тип параметра, а значения `Literal` или `Enum` должны быть все `str`, все `int` или все `float`. У параметра не больше 25 вариантов, имя варианта — от 1 до 100 символов, а строковое значение — не длиннее 100.

```python

```

`ctx.options` хранит уже заполненные параметры по их именам, преобразованные так, как их получил бы обработчик, если преобразование удаётся; параметр, который сейчас вводится, остаётся текстом. bostie отправляет первые 25 подсказок, обрезает имена длиннее 100 символов и отбрасывает подсказки с пустым именем, значением неверного типа или строковым значением длиннее 100 символов, с предупреждением в каждом случае. У параметра не может быть одновременно `choices` и `autocomplete`. Если функция выбрасывает исключение, ошибка уходит в [хуки ошибок](checks.md#error-hooks), а Discord получает пустой список.

## Подкоманды и группы { #subcommands-and-groups }

`bot.group(name, description)` регистрирует команду, состоящую из подкоманд, а `group.group(...)` добавляет внутрь неё группу подкоманд. Группы вкладываются только на один уровень, и в группе не больше 25 элементов:

```python
--8<-- "docs/snippets/commands/command_groups.py"
```

Так определяются `/roles give` и `/roles color set`. `@group.command(name=...)` даёт подкоманде имя, отличное от имени функции. `ctx.command_name` — полное имя выполненной команды, например `"roles color set"`, а `command.qualified_name` — то же самое для объекта команды.

Группа верхнего уровня принимает настройки команды, кроме `name`, `ephemeral` и `auto_defer`, и они действуют на все её подкоманды: `default_permissions`, `nsfw`, `guilds`, `contexts` и `integration_types` в Discord существуют только у команд верхнего уровня. Вложенная группа принимает обе локализации, `checks` и `extra`. Подкоманда принимает `name`, `description`, обе локализации, `ephemeral`, `auto_defer`, `checks` и `extra`. Проверки группы выполняются до проверок её подкоманд.

## Настройки команды { #command-settings }

```python
--8<-- "docs/snippets/commands/command_settings.py"
```

| Настройка | Значение |
|---|---|
| `name`, `description` | имя и описание вместо взятых из функции |
| `name_localizations`, `description_localizations` | текст для каждой локали; функция перевода описана в [«Регистрации команд»](registration.md#translations) |
| `ephemeral` | ответы видит только пользователь, если вызов не указывает иное |
| `auto_defer` | через сколько секунд ответ на неотвеченное использование откладывается; `None` отключает это ([«Ответы на взаимодействия»](responses.md#deferring)) |
| `default_permissions` | права, которые нужны участнику, чтобы видеть и использовать команду; администраторы сервера могут изменить, кому она доступна |
| `nsfw` | команда видна только в каналах с возрастным ограничением |
| `guilds` | ID серверов, на которых команда регистрируется вместо глобальной регистрации |
| `contexts` | где можно использовать глобальную команду: на серверах, в личных сообщениях с ботом, в приватных каналах |
| `integration_types` | в каких установках есть команда: установка на сервер, установка для пользователя |
| `checks` | проверки, которые выполняются до обработчика ([«Проверки»](checks.md)) |
| `extra` | сырые поля, которые добавляются в JSON команды |

`ephemeral`, `auto_defer`, `default_permissions`, `nsfw`, `contexts` и `integration_types` можно также задать для всех команд [роутера](routers.md#defaults), а `contexts`, `integration_types` и `auto_defer` — для всех команд бота.

## Лимиты { #limits }

Декоратор проверяет то, что отклонил бы Discord, и выбрасывает `CommandDefinitionError` с именем функции и параметра:

- Имена — от 1 до 32 символов из букв, цифр, `-` и `_`, без заглавных букв. Имена команд пользователя и сообщения могут также содержать заглавные буквы и пробелы.
- Описания — от 1 до 100 символов.
- У команды не больше 25 параметров, у параметра — не больше 25 вариантов.
- `*args`, `**kwargs`, параметры только для позиционной передачи и параметры без аннотации типа не принимаются.

Если имена, описания и значения вариантов команды в сумме превышают разрешённые Discord 8000 символов, об этом сообщает предупреждение, а не ошибка. Синхронизация предупреждает, когда в одной области больше 100 слэш-команд, 15 команд пользователя или 15 команд сообщения.
