## Источники { #sources }

Источник — это звук, который нужно проиграть. Каждый используется один раз: `play` открывает его, повторное открытие после окончания вызывает `StateError`, а `source.again()` возвращает новый источник с тем же звуком, чтобы проиграть его ещё раз.

| Источник | Проигрывает | Перемотка |
|---|---|---|
| `voice.File(path)` | локальный файл | да |
| `voice.Bytes(data, hint=None)` | содержимое файла в памяти; `hint` — расширение, например `"ogg"` | да |
| `voice.Url(url, headers=None)` | прямой HTTP- или HTTPS-URL медиафайла потоком или плейлист HLS | если сервер принимает запросы диапазонов; HLS — нет |
| `voice.FFmpeg(args, executable="ffmpeg")` | вывод команды ffmpeg — для форматов, которые bostie не декодирует | нет |
| `voice.Stream(items, format)` | асинхронный итерируемый объект с порциями PCM или пакетами Opus в формате `format` | нет |

`File`, `Bytes` и `Url` декодируются в Rust: Ogg (Opus, Vorbis), WebM и Matroska, MP4 и M4A (AAC), MP3, FLAC и WAV. URL должен указывать на сам медиафайл, а не на веб-страницу, которая его встраивает. Когда соединение с сервером обрывается, `Url` переподключается до трёх раз — через 0,5, 1 и 2 секунды — и продолжает с места обрыва, если сервер принимает запросы диапазонов. Главный плейлист HLS проигрывает свою звуковую версию, живой плейлист начинается за три сегмента до конца, а зашифрованные плейлисты и сегменты с диапазонами байтов отклоняются с `SourceError`. `FFmpeg` запускает программу с вашими входными аргументами и читает из её вывода стерео PCM 16 бит 48 кГц; он вызывает `SourceError`, если программы нет в `PATH` или она завершилась с ошибкой. Источник, который не удаётся открыть, декодировать или перемотать, вызывает `SourceError` или завершает свой трек с причиной `ERROR`.

После `open()`, который устанавливает `opened`, у источника есть `format`, `duration` (в секундах, `None`, если неизвестна), `seekable` и `tags` — `voice.Tags` с `title`, `artist` и `album`, которые указаны в файле.

## Треки { #tracks }

`vc.play(source, volume=1.0, filters=Filters(), meta=None)` принимает начальную громкость и фильтры, а также `meta` — любое значение, которое нужно хранить вместе с треком, например кто его заказал. Он также принимает `buffer` и `stall` для [синка](sinks.md) трека.

| `Track` | Что делает |
|---|---|
| `await track.wait()` | ждёт окончания и возвращает `TrackEnd`; отмена ожидания не останавливает трек |
| `await track.started()` | ждёт, пока трек начнёт играть; `False`, если он закончился раньше |
| `track.ended` | `TrackEnd` или `None`, пока трек играет |
| `track.position` | сколько секунд источника уже проиграно |
| `track.pause()`, `track.resume()`, `track.paused` | прекращают и возобновляют подачу звука; уже буферизованный звук всё равно доигрывает |
| `await track.seek(seconds)` | продолжить с позиции; `SourceError`, если источник не перематывается |
| `track.volume`, `track.filters` | меняются сразу, пока трек играет |
| `track.stop()` | завершить трек |
| `track.source`, `track.meta`, `track.sink` | что он проигрывает, ваше значение и синк, в который он пишет |

У `TrackEnd` есть `track`, `reason` (`FINISHED`, `STOPPED`, `ERROR` вместе с `error` или `CLEANUP`, когда подключение завершилось) и `may_start_next` — истина после `FINISHED` или `ERROR`, — которое говорит, должен ли ваш собственный плеер переходить к следующему треку. `vc.stop()` завершает все треки.

## Громкость и фильтры { #volume-and-filters }

`volume` умножает отсчёты: 0,5 — вдвое тише, 1,0 оставляет их без изменений. `voice.Filters` задаёт эффекты, которые Rust применяет во время воспроизведения:

| Поле `Filters` | По умолчанию | Диапазон |
|---|---|---|
| `equalizer` | `{}` | до 16 полос: центральная частота от 20 до 20 000 Гц сопоставляется с усилением в дБ; каждая полоса шириной в октаву |
| `bass` | 0.0 | усиление в дБ ниже 100 Гц |
| `speed` | 1.0 | от 0,5 до 2,0 с сохранением высоты тона |
| `pitch` | 1.0 | от 0,5 до 2,0 с сохранением темпа |

Усиление — от −24 до 24 дБ, а значения вне диапазона вызывают `ValueError`.

## Очереди { #queues }


`voice.Queue(vc)` проигрывает треки подряд без пауз или с перекрытием на `crossfade` секунд. Она принимает `volume`, `filters`, `crossfade` и `history`, по умолчанию взятые из настроек подключения, а также `buffer` и `stall` синка.

- `queue.add(source, meta=None, index=None)` ставит источник в конец очереди или на позицию `index` среди предстоящих треков и возвращает его `Track`.
- `queue.now`, `queue.upcoming` и `queue.history` — текущий трек, следующие и до `history` уже сыгранных.
- `queue.skip()` завершает текущий трек; `queue.back()` снова проигрывает последний трек из истории, а затем текущий заново.
- `queue.move(track, index)`, `queue.remove(track)`, `queue.shuffle()` и `queue.clear()` переупорядочивают предстоящие треки.
- `queue.loop = "track"` повторяет текущий трек, `"queue"` — всю очередь, `None` отключает повтор; тип — `voice.Loop`. Повторы используют `source.again()`.
- `queue.pause()`, `queue.resume()`, `queue.paused`, `queue.volume` и `queue.filters` действуют на то, что сейчас играет.
- `queue.stop()` завершает все треки; треки, добавленные позже, снова играют.
- `await queue.join()` ждёт, пока в очереди и в воспроизведении ничего не останется.

Очередь на завершённом подключении становится `closed` и больше не принимает треки; после переподключения создайте новую, как делает пример.

## Звуки звуковой панели { #soundboard-sounds }

`await bot.rest.soundboard.send(vc.channel_id, sound_id=...)` проигрывает звук звуковой панели в канале, к которому подключён бот. Discord проигрывает его в самом звонке, рядом со всем, что отправляет бот; для звука с другого сервера передайте `source_guild_id`. `bot.rest.soundboard.list_default()` перечисляет собственные звуки Discord, а `list(guild_id)` — звуки сервера; `bot.request_soundboard_sounds(guild_id)` запрашивает их через шлюз.

## Один и тот же звук на нескольких серверах { #the-same-audio-in-several-guilds }

`await voice.broadcast(source, connections)` проигрывает один источник в нескольких подключениях, декодируя и кодируя его один раз. Завершившиеся подключения выбывают из набора; присоединившиеся позже не добавляются. Функция принимает `encoder` и `stall`, по умолчанию `"drop"`, чтобы застрявшее подключение не задерживало остальные.

## Кодировщик { #encoder }

`voice.EncoderSettings` настраивает кодировщик Opus подключения — через `Defaults(encoder=...)`, `connect(encoder=...)` или `vc.encoder = ...` во время подключения:

| Поле | По умолчанию | Значение |
|---|---|---|
| `bitrate` | `None` | бит в секунду, от 500 до 512 000; `None` следует битрейту канала или берёт 64 000 |
| `application` | `"audio"` | `"audio"` для музыки, `"voip"` для речи, `"lowdelay"` для минимальной задержки |
| `fec` | `True` | упреждающая коррекция ошибок, которая скрывает потерянные пакеты |
| `packet_loss` | 0.1 | ожидаемая доля потерь от 0 до 1, на которую рассчитывает `fec` |
| `complexity` | 10 | от 0 до 10; меньшее значение тратит меньше CPU |
| `bandwidth` | `"auto"` | верхняя полоса звука: `"narrow"`, `"medium"`, `"wide"`, `"superwide"` или `"full"` |
| `signal_type` | `"auto"` | настройка под `"voice"` или `"music"` |

`vc.speaking_flags` задаёт флаги речи, которые объявляет бот: по умолчанию `voice.SpeakingFlags.MICROPHONE`, `SOUNDSHARE` для общего звука, `PRIORITY` для приоритетного режима.
