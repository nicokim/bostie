# Security policy

Please don't report a security problem in a public issue. Use GitHub's private vulnerability reporting instead, through the "Report a vulnerability" button on the repository's Security tab. Only you and the maintainers can see the report.

Security problems include anything that exposes a bot token or weakens DAVE's end-to-end encryption. Say which bostie commit you used and how to reproduce the problem, and leave your token out of any code you send.
